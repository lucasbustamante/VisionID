# VisionID 1.5

## Ajustes finais

- versão do aplicativo atualizada para `1.5` (`versionCode 11`);
- diagnóstico WebView removido por completo: botões, Activity, layout, Manifest e variante `diagnostic`;
- inspeção remota do WebView desativada;
- opção "Diagnóstico do WebView" removida da área técnica;
- abertura/fechamento da área técnica não gera nem exibe registros nos logs;
- botão "Fechar jornada" do GeckoView/N960K:
  - permanece expandido por 5 segundos;
  - reduz para apenas `✕`;
  - pode ser arrastado horizontalmente;
  - encaixa automaticamente no lado esquerdo ou direito.
