# Correção de compatibilidade de dependências

Alterações aplicadas:

- Android Gradle Plugin: `8.7.3` → `8.11.1`
- Gradle Wrapper: `8.9` → `8.13`
- `compileSdk`: `35` → `36`
- `targetSdk` mantido em `35`
- Catálogo `libs.versions.toml` alinhado às versões efetivamente usadas pelo projeto

Antes de compilar, instale o Android SDK Platform 36 no SDK Manager.
